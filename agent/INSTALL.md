# Установка и запуск агента «Распределение ФУЛ между логистами»

## Состав архива `agent.zip`

| Файл | Что это |
|---|---|
| `logist-distribution.zip` | навык в формате GigaCowork: папка `logist-distribution/` с `SKILL.md`, `scripts/`, `references/` |
| `system_prompt.txt` | системный промпт агента (без привязки к конкретному инструменту) |
| `INSTALL.md` | эта инструкция |

## Установка в GigaCowork

1. Создайте агента, например «Распределение ФУЛ».
2. Вставьте содержимое `system_prompt.txt` в поле системного промпта агента.
3. Загрузите навык `logist-distribution.zip` (внутри — папка `logist-distribution/` с `SKILL.md`)
   и подключите его к агенту.
4. Требования к окружению: Python 3.9+, пакеты `openpyxl` (обязательно) и `xlrd`
   (только для файлов `.xls`). Сеть и внешние сервисы не нужны.

## Запуск

1. Выберите агента.
2. Приложите три выгрузки Excel: ФУЛ из 1С, реестр Cloud, сотрудники из 1С
   (имена файлов, листов и порядок колонок не важны; можно одной книгой с тремя листами).
3. Отправьте сообщение **без текста**.

Агент запустит скрипт навыка, приложит `distribution_result.xlsx` и ответит по шаблону:

```
Готово: distribution_result.xlsx
• Новых строк для Cloud: 20 (с логистом — 14, без логиста — 6)
• Повторных отправок: 5 (заказ уже в Cloud — 4, дубль в пачке — 1)
• Возможных пропусков: 1
• Вопросов, требующих решения: 13 (срочных — 7)
Срочно:
  – нет номера заказа — строка не создана: УЛ-26-0108
  – группа не определена (нет или незнакомый способ доставки / страна): УЛ-26-0111, УЛ-26-0112
  – в группе нет доступных логистов: УЛ-26-0105, УЛ-26-0118, УЛ-26-0121, УЛ-26-0125
Подробности — на листах «Требует внимания» и «Журнал решений».
```

## Запуск скрипта без агента (для проверки)

```bash
unzip logist-distribution.zip
python3 logist-distribution/scripts/distribute.py ful.xlsx cloud.xlsx staff.xlsx --out ./result
# или папка с файлами:
python3 logist-distribution/scripts/distribute.py ./attachments --out ./result
```

Коды выхода: `0` — успех, `2` — ошибка входных данных (текст начинается с `ОШИБКА:`).

## Запуск в Docker (без установки Python)

```bash
docker build -t logist-agent .          # из корня репозитория
docker run --rm --user "$(id -u):$(id -g)" \
  -v "/путь/к/выгрузкам:/data/in:ro" -v "$PWD/result:/data/out" logist-agent
```

Готовый образ публикуется при выпуске версии: `ghcr.io/<владелец>/<репозиторий>:<версия>`.

## Настройка правил без правки кода

`logist-distribution/references/rules.json`:
- синонимы заголовков колонок (`headers`);
- ключевые слова должностей и исключаемых ролей (`position_group_keywords`, `position_excluded_keywords`);
- допустимые состояния сотрудника (`available_states`);
- способы доставки и их написания (`delivery_methods`);
- статус новой строки, шаблон комментария о повторе, учёт пачки в загрузке и др.

`logist-distribution/references/countries.json` — что считается Китаем для группы ВЭД.
