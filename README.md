# Агент распределения заказов между логистами (GigaCowork)

Тестовое задание «Фабрика решений»: AI-агент, который по трём выгрузкам Excel
(ФУЛ из 1С, реестр Cloud, сотрудники из 1С) определяет новые упаковочные листы,
группу и логиста и готовит строки реестра Cloud строго по его форме.

> Работа в процессе. Структура репозитория будет описана по мере готовности.
