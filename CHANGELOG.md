# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии навыка — `references/rules.json → version`.

## [1.1.1] — 2026-11-12

Поведение распределения не изменилось: на всех наборах данных результаты совпадают с 1.1.0
побайтно по содержимому листов (те же хеши в `runs/metrics.json`).

### Исправлено
- Результат записывается атомарно (`*.part` → переименование): при сбое записи не остаётся
  битого `distribution_result.xlsx`.
- Пустая папка входа: понятная ошибка «в папке … нет файлов Excel» вместо «не переданы файлы».
- Нет прав на запись в папку результата: понятная ошибка и код 2 вместо трейсбека
  (нашлось при запуске в Docker от непривилегированного пользователя).

### Инфраструктура
- `pyproject.toml`: ruff (линтер + форматтер, версия закреплена), pytest, покрытие ядра ≥ 85% (сейчас 93%).
- Тесты: 30 вместо 21 — CLI в том же процессе, `.xls`, атомарная запись, ошибки прав и пустой папки;
  каждый модуль запускается и отдельно, и под `unittest`, и под `pytest`; маркер `e2e`.
- Docker: многостадийный образ (`runtime` — навык от непривилегированного пользователя, `test` — ruff + pytest);
  базовый образ и индекс пакетов подменяются на корпоративные зеркала через `--build-arg`.
- CI (GitHub Actions): ruff → тесты на Python 3.9/3.11/3.12/3.13 с покрытием → контрольные прогоны
  с порогами из БТ (`run_control.py --strict`) → сборка и запуск Docker-образа → архивы для сдачи.
- CD: тег `vX.Y.Z` → проверка версии и тестов → GitHub Release с `agent.zip`, `testdata.zip`, `report.pdf`
  → образ в GitHub Container Registry.
- pre-commit (ruff, проверки YAML/TOML), Dependabot, цели Makefile `lint`, `format`, `cov`, `check`, `docker-*`.

## [1.1.0] — 2026-11-11

### Изменено
- Ответ в чат стал короче: срочные вопросы сгруппированы по типу («нет номера заказа»,
  «группа не определена», «нет доступных логистов») со списком номеров ФУЛ.
- В «Требует внимания» приоритет «Блокирует» переименован в «Срочно».
- SKILL.md и системный промпт требуют копировать ответ дословно, без служебных строк и путей.

### Добавлено
- Файл `chat_message.txt` с готовым ответом для чата.
- Метрика «ответ в чат = шаблон» в контрольных прогонах.

### Почему
Первый раунд агентных прогонов (9 штук) показал: Excel-результат верен во всех прогонах,
но при пересказе длинного ответа модель дважды оставила служебную строку и один раз исказила
текст. После изменений все 9 ответов второго раунда совпали с шаблоном дословно.

## [1.0.0] — 2026-11-11

### Добавлено
- Навык `logist-distribution`: распознавание трёх выгрузок по заголовкам, правила статуса ФУЛ,
  группы и логиста, результат Excel из 7 листов с журналом решений, ответ в чат по шаблону.
- Системный промпт и инструкция по установке.
- Синтетические данные (3 набора) с эталоном, заданным вручную, и скрипт метрик.
- Harness для GigaChat API с function calling.
